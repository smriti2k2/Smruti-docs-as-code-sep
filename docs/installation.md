# Installation
 
This section describes how to install and deploy the BMC AMI Platform, deploy additional services, configure CRA, and upgrade BMC AMI Platform. The following links provide detailed information for each task.
## Prerequisites
 
You can deploy BMC AMI Platform on an RKE2 Kubernetes cluster and Red Hat OpenShift. BMC AMI Platform supports a modular deployment model that enables you to deploy only the capabilities required for your use case.
 
- Administrator access
- Internet access
- The installation package
 
## Install the product
 
1. Download the installation package.
2. Open the downloaded file.
3. Follow the installation wizard.
   1. Select **Install**.
   2. Select **Finish** when the installation is complete.
 
## Verify the installation
 
Open the application and sign in using your account.
 
## Next steps
 
After installation, continue with the [Getting Started](getting-started.md) guide.
